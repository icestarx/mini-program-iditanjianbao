# 测试用例清单

## 1. 教程与账本

- 首次登录只发一次 500C。
- 教学交易按 500 → 440 → 620 → 420 变化。
- 教学赠一次专家报告体验券，不可重复领取。
- 普通鉴定每天首次免费，后续收费正确。
- 断网或刷新后不重复发奖、不重复扣费。

## 2. 固定货架

- 玩家进入同一摊位时，读取相同的 10 件固定货品配置。
- 全部配置为 12 个摊位、每摊 10 件，共 120 个固定货位。
- 不因进入时间、玩家或页面刷新随机改变货品和顺序。
- 每件货品达到 `max_purchases_per_user` 后不可继续购买。
- 真古董的累计购买上限为每位玩家 1 次。

## 3. 购买与砍价

- 未解锁摊位不可购买。
- 现金不足时拒绝购买且不产生库存记录。
- 仓容不足时拒绝购买且不扣现金。
- 同一 `request_id` 重试购买只成功一次。
- 砍价最多 3 轮。
- 出价低于 `floor` 不成交。
- 跨业务日的砍价会话返回 `MARKET_ROUND_EXPIRED`。

## 4. 鉴定与复盘

- 购买后的成交回执不返回真伪、估值或专家证据。
- 普通鉴定只显示类别和宽幅估值。
- 专家鉴定返回新增事实、证据链和复盘。
- 三种专家路径：现金、券、8小时免费，结论一致。
- 已解锁的道具线索不重复扣费。
- 未配置的紫光灯线索置灰，不可购买或使用。

## 5. NPC 与令牌

- 同一 NPC 双摊共用好感、信任和每日对话次数。
- 每位 NPC 只能发放一枚青睐令牌。
- 重复领取令牌不增加奖励。
- 负面对话不会永久锁死，次日可补救。
- 未解锁的秘密不返回原文。

## 6. 知识库隔离

- `knowledge_artifact` 不进入交易货池。
- 今日知识文章只读，不加 C/G。
- 未发布文章不可通过接口访问。
- 馆藏图片加载失败时显示官方链接，不用商品图替代。

## 7. 支付与订单

- 客户端伪造支付成功回调不发货。
- 服务端验单通过后才发放 `G`。
- 同一 `platform_transaction_id` 只发货一次。
- 同一 `order_id` 重复通知不重复发放。
- 充值订单与退款订单分别落库，可关联原订单和渠道单号。
- 重复支付通知按渠道事件 ID 去重，不重复发放 `G`。
- 退款“已受理/处理中”不显示为退款成功；最终成功须由回调或查单确认。
- 退款累计金额不能超过原支付金额。
- 重复退款通知只处理一次；结果未知时以同一商户退款单号查单/重试。
- 退款成功后写账本和虚拟权益处理记录，不修改历史流水或产生负余额。

## 8. 并发与幂等

- 同一 `request_id` 重复请求只执行一次。
- 并发出售同一 `ownership_id` 只到账一次。
- 并发购买同一 `listing_id` 只成功一次。
- 并发领取任务奖励只发一次。
- 并发升级店铺只扣一次费用。

## 9. 微信端到端

- 微信登录、授权、断网恢复。
- 真机市场、砍价、购买、鉴定、出售全流程。
- 支付能力检测和支付入口隐藏逻辑。
- 未成年人保护和消费限额。
- 包体大小、启动速度、图片加载和崩溃率。
