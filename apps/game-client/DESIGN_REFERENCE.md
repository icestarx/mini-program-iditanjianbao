# Demo UI/UX 实现基准

目标是复刻 `taobao_demo_v161.html` 的移动端体验。新增地图只增加“点击摊位切换”的入口，沿用 demo 的页面框架、卡片、按钮和底部导航。

## 核心页面顺序

1. 市场首页：欢迎区、账户资源、NPC 摊主入口和可点选老街地图。
2. 摊位详情：摊主头像/简介、固定 10 格货架和锁定摊位状态。
3. 物件观察：货品视觉、挂牌价、四条观察特征和放大镜/紫光灯入口。
4. 购买前判断：类别、观察依据与信心程度；不揭示隐藏答案。
5. 砍价：显示摊主、报价、出价输入、话术选择和剩余回合。
6. 成交回执：显示买价和入库结果，不显示真伪/估值。
7. 鉴定服务、专家报告和判断复盘：按 V1.5 顺序解锁。
8. 我的藏馆：库存、已鉴定状态、出售和历史记录。

## 交互基准

- 地图点位和摊位列表都进入同一个固定 `stall_id`；地图不生成或重排货品。
- 摊位每次显示同一组 10 个 `stall_product_id` 和同一配置顺序。
- 购买成功后本地显示服务端/mock API 回执；已购货品在仓库可见。
- 达到玩家累计限购后，货品保留在摊位原位置并显示不可购买状态。
- 页面组件只依赖 API adapter DTO，不读取完整货品配置。
- 所有 loading、空状态、失败提示沿用 demo 的轻量卡片和清晰下一步操作。

## 首轮体验验收路径

`集市 → 地图选摊 → 查看固定货架 → 观察商品 → 记录判断 → 砍价购买 → 成交回执 → 仓库`

首轮只验这条主流程和 demo 的视觉一致性；后续再扩展其余页面与剧情内容。
